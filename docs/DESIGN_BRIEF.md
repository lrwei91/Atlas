# Atlas 界面设计简报

这是一个面向个人知识库维护者的内容工作台，以微暖纸面、黑墨和荧光黄建立笔记浏览与持续阅读的编辑式呈现。依据 project-standards 的 visual-style、responsive-design、ux-interaction 与 accessibility；保留导航、筛选、分享、编辑及缓存契约。

## 本轮取舍

- 统一工作台、登录与分享页的颜色、字体、表面、边框、焦点和文章排版，公共样式真源为 `public/atlas-ui.css`。
- 加强品牌字标、中文衬线标题、黄色划线与选中标记；正文和操作采用系统字体。保留浅色，不引入外部字体或持续装饰动效。
- 密度保持工作台需求：桌面侧栏与卡片、手机封面瀑布流，不采用个人主页的大型首屏、插画或宣传构图。
- 普通卡片不播放入场动画，避免列表复用与重排造成闪动；仅保留操作反馈，减弱动效模式近即时完成。
- 手机顶部与详情、账户工具栏统一为 80px 加安全区，按钮上间距 16px，命中区域至少 44px；菜单避让工具栏。桌面顶栏为 72px。
- 手机不足 22rem 时按原列表顺序切为单列；正常手机使用双列。标题、正文和主要元信息使用相对字号，长内容局部滚动。
- 列表与搜索卡片补充链接语义、键盘焦点及 Enter 打开；底部当前页面增加非颜色标记与 aria-current。
- 分类抽屉提供 44px 明确关闭按钮；抽屉和详情操作菜单打开时进入控件，关闭时恢复触发器焦点。

## 验证边界

运行回归与真实浏览器检查分别记录。视口模拟覆盖 320、390、768、1024、1440 及短横屏；检查列表、详情、搜索、抽屉、菜单与账户页。真机 Safari、软键盘、系统字体、辅助放大和读屏仍需独立验收，不以截图或 jsdom 替代。

本轮浏览器结果：五种宽度均无页面横向溢出；320px 265 张卡片全部按顺序进入单列，390px 正常双列。首页与详情按钮顶部为 16px、命中高度 44px；390×844 抽屉满高，732×390 抽屉可滚动。真实搜索、详情、更多菜单、账户及登录页面已检查。分享访问与撤销、编辑保护、导航、缓存及单列顺序通过 `npm test`；分享页本轮未单独做真实链接视觉验收。
