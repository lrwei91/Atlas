# 服务器分享

Atlas 的新分享链接为 `<ATLAS_PUBLIC_URL>/s/<22 位随机标识>`，
页面、文档和媒体均由 Atlas 提供，不再发布到 GitHub。

- 主库和管理 API 仍需登录，只有主动分享的单篇文档开放访问。
- 分享页仅可读取该文档及其解析引用的附件，不允许浏览其他笔记或附件。
- 内容随文档变化，保存后无需重新发布。
- 再次复制同篇文档的分享链接保持标识不变。
- 取消分享或删除文档后，页面、文档接口和附件接口均失效。
- 旧分享已全部撤销；不支持旧 `/share/` 路径、64 位旧标识或 GitHub 重定向。

正式公网分享须在目标域名的 HTTPS、DNS 与服务器备案条件验证后启用。
通过 `127.0.0.1` 私有转发生成的链接仅用于本机测试，其他设备无法直接访问。

`npm test` 中的 `local-share-test.js` 和 `auth-test.js` 验证分享创建、媒体范围、
编辑即时更新、撤销、删除联动和旧路径拒绝。测试使用临时笔记与账号。
