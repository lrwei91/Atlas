Atlas · 移动端布局 Demo v0.6

参考小红书 / 抖音截图的排版语言，重构 Atlas 手机端信息架构。仅改结构与样式，桌面端（≥768px）零改动。

v0.6 变更（对照 v0.5）

  • 接入 3 张真实封面图：卡片有cover 字段时显示图片，无则回落到分类色块占位，两种形态混排
  • 图片已压至900px 宽 JPEG（单张约 90KB），原始 2MB PNG 已弃用
  • 封面比例由 16:10 改为 16:9，与原图 900×506（1.778）完全一致，实测 object-fit:cover 下零裁切；卡片高度由 115px 降至 104px
  • Demo 内以base64 内联，保证 file:// 与跨源预览下都能显示
  • 深色主题下对封面加 brightness(.86) 轻微压暗，避免浅色图在黑底上过于刺眼

v0.5 变更（对照 v0.4）

  • 详情页顶栏标题移除：标题已在正文首行呈现，顶栏只留「返回 / 分享 / 更多」三个按钮
  • 全局隐藏滚动条：* { scrollbar-width:none } + ::-webkit-scrollbar 置零，滚动能力保留
  • 左缘右滑返回：从屏幕左缘 24px 内起手、横向位移达88px 时触发，页面跟随手指并露出底层页面与返回箭头；未达阈值回弹。详情页 / 我的页 / 侧栏抽屉均已接入
  • 返回顶部悬浮按钮：首页与详情页各一个，滚动超过阈值后淡入（38px 磨砂圆形），点击平滑回顶
  • 顺带修复：瀑布流无法滚动 —— column-count 会把内容均分到与容器等高，容器永不溢出。改为外层 .feed-body 承担滚动，.feed 只负责分列

v0.4 变更（对照 v0.3）

  • 顶栏移除品牌区：「Atlas + 笔记数/数据源」整块删除，顶栏只留左侧菜单与右侧搜索两个圆形按钮，中间为空
  • 品牌标识下移至侧栏：侧栏头部由「分类 12 篇」改为 Atlas 大字 + 副标题「12 篇 · 本机主库/示例数据」，并加分隔线

v0.3 变更（对照 v0.2）

  • 分享页移除筛选：chip 筛选行整行隐藏，时段与排序不再作用于分享列表，固定按时间倒序
  • 「我的」改独立页面：不再是右侧抽屉，改为全屏页面（状态栏 + 返回/标题 + 账户卡 + 统计 + 最近浏览 + 操作列表）
  • 详情页按参考图改造：顶部保留系统状态栏；标题栏为返回 / 标题 / 分享 / 更多；移除头像昵称与关注按钮；编辑、复制链接、取消分享、删除全部收进右上角更多菜单；底部固定操作条移除
  • 状态栏改为全局浮层（z-index 96），首页 / 详情页 / 我的页共用，各页顶部自行留白 44px
  • 正文排版对齐参考图：路径信息降级为顶部一行小字（含日期与分享状态），大标题置顶加重

v0.2 变更（对照 v0.1）

  • 侧栏移除「分享笔记」入口，分类项移除「xx 篇」计数（仅保留名称）
  • 顶栏移除「发现 / 分享 / 近期」分段 tab，改为居中品牌区（Atlas + 笔记数/数据源）
  • 视图标题条移除「随机一篇」按钮
  • 底栏「搜索」→随机（打开随机一篇）；原「随机」凸起键→新增（新建空白 md）
  • 底栏「我的」页补全：6 项统计、最近浏览、操作区、真实退出登录

需要拍板的取舍点

  • 新增文档落点：统一写 notes/新建/（当前 Demo 行为）／ 写入当前分类目录／ 弹出目录选择器
  • 重名策略：自动加时间戳后缀／ 直接拒绝并提示
  • 封面图策略：分类色块占位（零后端改动）／ 解析笔记首图作封面（改 server.js，需缓存与裁剪）／ 人工指定图库目录（新增 cover 字段映射）
  • 封面图存放位置：Demo 用 public/covers/ 静态目录。正式版若走笔记内嵌图片，需处理 /files/ 鉴权路径与缩略图生成
  • 主题：沿用 Atlas 现有「白纸油墨」浅色，还是引入参考图的深色沉浸式（后者需补深色 token）
  • 瀑布流排序：CSS 多列按高度填充，视觉顺序与时间顺序不一致，是否可接受
  • 搜索入口：底栏已无搜索位，现仅顶栏放大镜可用，是否在「我的」页补一个搜索项
  • 品牌标识位置：已移至侧栏，首页顶栏无产品识别；侧栏关闭时只剩「全部笔记 12 篇」，是否可接受
  • 右滑手势与浏览器返回：正式版若沿用 hash 路由，浏览器自带右滑返回会与本手势叠加，需二选一（建议沿用手势、把浏览器历史交给 replaceState 管理）
  • 阅读页操作：分享 / 编辑 / 删除是否收进「更多」
  • 「分享」视图：顶栏与侧栏入口已移除，目前仅底栏「分享」可达，是否可接受
